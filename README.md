# E-commerce Sales Analysis

## Overview
Analyzed the Superstore Sales dataset to uncover trends in sales, customer behavior, and product performance.

## Problem
Retail businesses need insights into regional sales, top customers, and product profitability to optimize operations.

## Approach
- **Excel**: Conditional formatting to highlight cells less than average sales, created pivot tables and charts for sales and profit by region and category, calculated KPIs (revenue, profit margin, top region sales and Order frequency).
- **SQL**: Queried top customers, sales trends, and inventory using SQLite.
- **Tableau**: Built an interactive dashboard with filters for region, category, and time.

## Tools
- Excel, SQLite, Tableau Public
